## This guide covers:
 **Running est-proxy on AWS EC2**

### SSH to EC2
```bash
ssh ubuntu@"$EC2_HOST"

# Example:
ssh ubuntu@openwifi2.routerarchitects.com

```
### On EC2, the directory layout should be as:
```
ubuntu@openwifi:~/est-proxy-server$ tree
.
├── data
│   ├── certs
│   │   ├── est-srv.crt.pem
│   │   └── est-srv.key.pem
│   ├── est_proxy.cfg
│   ├── openssl
│   │   └── certs
│   └── openssl-ca
│       ├── cacert.pem
│       ├── issuer-cert.pem
│       ├── issuer.cnf
│       ├── issuer-crl.pem
│       └── issuer-private.pem
└── docker-compose.yml
```

###  Create the directory:
```bash
mkdir -p ./est-proxy-server/{data/certs,data/openssl/certs,data/openssl-ca} && cd est-proxy-server/
```

### Follow [Deploy.md](./Deploy.md) to Generate and Copy the server key/cert and issuer+CA key/cert into the data/ paths above.

### Create `docker-compose.yml`:
```bash
cat > docker-compose.yml <<'YAML'
services:
  est-proxy:
    image: DOCKERHUB_USER/IMAGE_NAME:TAG  # Example: image:openwifi12/est-proxy-server/1.2.0
    volumes:
      - type: bind
        source: ./data
        target: /usr/local/est_proxy/data
        read_only: false
      - type: bind
        source: /etc/timezone
        target: /etc/timezone
        read_only: true
      - type: bind
        source: /etc/localtime
        target: /etc/localtime
        read_only: true
    ports:
      - "8001:17443"
    restart: always

networks:
  default:
    name: est
    driver: bridge
YAML
```

### Create est_proxy.cfg with required configuration
```
cat > ./data/est_proxy.cfg <<'CFG'
[DEFAULT]
debug = True
connection_log = True

[Daemon]
address = 0.0.0.0
port = 17443
key_file = /usr/local/est_proxy/data/certs/est-srv.key.pem
cert_file = /usr/local/est_proxy/data/certs/est-srv.crt.pem

[main]
ca_handler = openssl
services = cacerts,simpleenroll,simplereenroll

[CAhandler]
handler_file = examples.ca_handler.openssl_ca_handler

# ---- MANDATORY for enroll ----
issuing_ca_key = /usr/local/est_proxy/data/openssl-ca/issuer-private.pem
issuing_ca_cert = /usr/local/est_proxy/data/openssl-ca/issuer-cert.pem
issuing_ca_crl = /usr/local/est_proxy/data/openssl-ca/issuer-crl.pem

# Optional/defaults
cert_validity_days = 365
cert_save_path = /usr/local/est_proxy/data/openssl/certs

# If certificates are generated by the issuer and include additional CAs,
# then specify the path to the CA certificates here in the ca_cert_chain_list.
# The est_proxy will concatenate all certificates with the issuer's certificate
# and create a CA certs file in pkcs7 format which will be sent to the device.
# If there is no issuer and only the CA is generating the device certificates,
# then this list will remain empty.
ca_cert_chain_list = ["/usr/local/est_proxy/data/openssl-ca/cacert.pem"]

# Minimal extensions profile (optional but good to have)
openssl_conf = /usr/local/est_proxy/data/openssl-ca/issuer.cnf

whitelist = []
blacklist = []
save_cert_as_hex = true
CFG
```
**Ensure the image already built and pushed to Docker Hub from your workstation before Pull & run.**

###  Pull & run

```bash
docker-compose up
```
#### NOTE-
**Ensure your EC2 Security Group allows inbound TCP on the mapped host port 8001 from your source IPs, and that no other service is bound to that port.**

###  Verify

**From EC2:**
```bash
docker ps
docker logs -f est-proxy

# To test the setup is working fine run this command it will return the cacerts
curl -vk https://127.0.0.1:8001/.well-known/est/cacerts
```

**To test the setup is working run this command remotely**
```bash
curl -vk https://$EC2_HOST:8001/.well-known/est/cacerts
# Example:-
curl -vk https://openwifi2.routerarchitects.com:8001/.well-known/est/cacerts
```
